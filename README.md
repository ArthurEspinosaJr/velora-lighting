# VELORA — Light, thoughtfully shaped

A fictional lighting studio with an interactive 3D showroom, created as a professional website concept by QuoteForge.

## Experience

- Three procedural 3D lamp designs: Mora, Arc, and Column.
- Three material finishes, adjustable glow, drag rotation, keyboard-friendly rotation controls, and pause/reset.
- Responsive editorial layout, scroll reveals, reduced-motion support, and a WebGL fallback.
- Downloadable local lighting briefs. No checkout, backend, email collection, or form submissions.
- AI-generated interior concept photography.

## Run locally

Serve this directory with any static web server. ES modules require HTTP rather than opening index.html directly.

## Hosting

GitHub Pages: deploy the `main` branch, `/ (root)` folder.

Live site: https://arthurespinosajr.github.io/velora-lighting/
